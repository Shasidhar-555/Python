================================================================================
TASK 5.3: IMPORT SYNTAX EVALUATION & NAMESPACE COLLISION ANALYSIS
================================================================================
1. import attendance.stats
   - Scope: Binds only top-level name 'attendance' into local symbol table.
   - Invocation: attendance.stats.percentage(3, 4)
   - Advantage: Completely eliminates naming collisions; explicit provenance.
   - Disadvantage: Verbose dotted path in high-frequency calculations.

2. from attendance import stats
   - Scope: Binds module object 'stats' directly into caller's local namespace.
   - Invocation: stats.percentage(3, 4)
   - Advantage: Balanced readability; preserves module namespace protection.
   - Disadvantage: Collides if local variable or another module is named 'stats'.

3. from attendance.stats import percentage
   - Scope: Binds function object 'percentage' directly into caller's local namespace.
   - Invocation: percentage(3, 4)
   - Advantage: Most concise and idiomatic for tightly coupled mathematical routines.
   - Disadvantage: Highest risk of shadow masking if local scope redefines 'percentage'.
