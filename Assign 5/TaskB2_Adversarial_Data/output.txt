Technical Explanation of Speedup:
  executemany() wraps the entire batch inside a SINGLE database transaction BEGIN...COMMIT,
  amortizing disk journal writes and lock acquisitions over N rows. Calling execute() in a
  loop with individual commits incurs N distinct disk syncs (fsync), degrading runtime by >15x.
